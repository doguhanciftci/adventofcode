# Advent of Code Solutions

This repository contains my solutions for the [Advent of Code](https://adventofcode.com/) programming challenges.

## About Advent of Code

Advent of Code is an annual event featuring daily programming puzzles from December 1st through December 25th. Each puzzle consists of two parts, with the second part typically building upon or extending the first.
